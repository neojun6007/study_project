# 학습 모드
| 말하면 | 동작 |
|---|---|
| `시작 [과목]` | 진도·복습일정 읽기 → 기한 된 복습 3문항 → 오늘 목표 제시 |
| (기본) 소크라테스 | 짧은 설명 + 질문 1개, 힌트 우선, 옆길 질문 환영 후 복귀 |
| `그냥 알려줘` | 힌트 없이 바로 명확한 설명 |
| `내가 설명할게` | 역할 반전: Claude가 헷갈리는 학생 역할로 허점 질문 |
| `함정 문제` | 그럴듯한 오류 설명 찾기 / 시험식 문제 |
| `연결해줘` | 지금 개념을 이전 챕터·다른 과목과 연결 (교차 학습) |
| `복습` | review_schedule.md에서 기한 된 항목으로 퀴즈 |
| `정리해줘` / `끝` | CLAUDE.md 저장 규칙 1–6 수행 |
